Finsight

A Python-based personal finance analytics application that converts bank-statement data into clear financial insights.

PythonStreamlitPandasData AnalyticsPersonal Finance
GitHub repository ↗
Data pipeline / financial analytics
01 / Context

The problem

Personal bank-statement data is often difficult to turn into a clear picture of spending behaviour and savings performance. Finsight was built to convert raw transaction data into a simple analytical view for the user.

02 / Build

What I developed

I built the application in Python and Streamlit. It accepts user-uploaded bank-statement CSV files, detects supported formats and delimiters, and normalizes the data through dedicated bank parsers with a generic fallback parser.

03 / Analysis

What the application calculates

  • Income and expenses.
  • Savings rate.
  • Category-level spending.
  • Monthly spending and income trends.
  • Rule-based transaction categorization.
04 / Output

How insights are presented

The processed data is presented through an interactive dashboard designed to make the underlying financial behaviour easy to understand quickly.

Design principle The focus is not only on processing data correctly, but on deciding which metrics turn raw transactions into useful financial insight.
05 / Skills

Relevant Skills

Python, pandas, Streamlit, data cleaning, rule-based categorization, financial analytics and dashboard design.
