Finsight

A personal finance app that turns your bank statements into a clear picture of your money. It runs on your own computer, so your statements never leave your device.

Python pandas Streamlit Plotly
Try the demo ↗ View the code ↗

The demo runs on made-up statements. Beta, version 0.2.0.

Private by design
0 accounts, servers or bank logins.
Everything runs locally.
01 Problem

Three ways to track your money, each with a catch

If you have accounts at several banks, each bank's app only shows its own account. Budgeting apps want your bank login or keep your data on their servers. A spreadsheet is private, but takes hours every month.

I wanted the full picture without giving up the data.

02 Product

Drop in your statements, get the picture

Export a CSV from each bank and drop the files in. Finsight combines them into one view of income, spending, savings and where the money went.

It also has budgets, savings goals, a month-end spending forecast, currency conversion, and CSV and Excel export.

03 Build

Calculated, not generated

Every number and insight comes from plain Python rules that can be read and tested. A recurring payment, for example, needs three payments at a regular interval. Nothing is guessed.

Five banks

Revolut, Wise, ING, Rabobank and bunq, plus a fallback for other CSV files.

One dashboard

Income, expenses, savings rate and monthly trends in a single view.

Two forms

A browser app, and a Windows desktop program that needs no Python installed.

No server

Each user's own computer does the work. A private session writes nothing to disk.

The core logic (parsing, categorising, transfer detection, insights) is kept separate from the interface, which is what made the desktop version possible without rewriting it.

04 Status

Where it stands

Finsight is a working product: the online demo is live and a Windows desktop beta is built. I am the sole developer and I use it on my own statements.

What is not done yet

It has no outside users yet. The ING, Rabobank and bunq readers are built from documented formats and have not been verified against real exports. Next: first testers, a signed installer and a Mac version.
